Supported Features & Technical Guide

How CopyPaste Freedom safely restores interactions on restricted pages.

TEXT SELECTION

CSS & Event Overrides

Removes user-select: none, -webkit-user-select: none, and unblocks selectstart listeners across all content elements while safeguarding UI buttons, tabs, and forms.

COPY RESTORATION

Capture-Phase Copy Guard

Intercepts the copy event at the capture phase before malicious page scripts can execute e.preventDefault(). Restores Ctrl + C hotkeys without altering clipboard contents.

PASTE RESTORATION

Input & Textarea Unblocking

Prevents websites from disabling paste on text fields, email inputs, and password confirmations. Respects user-triggered paste actions and browser security standards.

RIGHT-CLICK CONTEXT MENU

Contextmenu Interception

Neutralizes document.oncontextmenu and suppresses cancellation events, allowing the native browser right-click menu to open anywhere.

🔒 Safety & Ethical Scope

CopyPaste Freedom operates entirely locally in your browser. It does NOT bypass DRM, paid paywalls, authentication tokens, or sensitive OS-level protections. It does not record, log, or transmit any clipboard contents.
